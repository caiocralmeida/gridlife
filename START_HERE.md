# 🏁 GRIDLIFE - Quick Start

## ⚡ Começar Agora

### 1. Abra no Navegador
```
Clique em: index.html
```

### 2. Espere Carregar
Você verá o menu principal com:
- Nova carreira piloto
- Modo livre piloto
- 👥 **MODO GESTOR** ← NOVO!
- Importar save

### 3. Clique em "Modo Gestor"

### 4. Crie Seu Gestor
- Nome
- Estilo (5 opções)
- Categoria (Kart → F1)
- Dificuldade
- Dinheiro inicial

### 5. Jogue!

## 🆘 Se não funcionar

### Problema: Página em branco
**Solução**: 
1. Abra console (F12)
2. Procure por erros em vermelho
3. Recarregue página (Ctrl+F5)

### Problema: "Modo Gestor" não aparece
**Solução**:
1. Limpe cache (Ctrl+Shift+Del)
2. Abra em nova aba
3. Tente em outro navegador (Chrome, Firefox)

### Problema: Jogo trava
**Solução**:
1. Abra console (F12)
2. Digite: `draw()`
3. Pressione Enter
